# Archive — ancien projet EduConnect

Ce dossier contient le code d'un projet précédent (EduConnect, plateforme
élèves/profs avec Supabase) qui occupait ce dépôt avant sa réaffectation au
site AM ("All Money").

Il n'est **pas importé** par l'application Next.js (rien dans `src/app` n'y
fait référence) et peut être supprimé sans risque dès que tu confirmes que tu
n'as plus besoin d'y revenir — le code reste de toute façon consultable dans
l'historique git (branche `main`).
